# Unbound Academics
Local tutoring for Houston-area students. Static HTML/CSS/JS site.

## Deploy on GitHub Pages
1. Push these files to the main branch
2. Repo Settings → Pages → Source: "Deploy from a branch" → main / root
3. Add your custom domain in the Pages settings, then update DNS at Namecheap

## Contact form
Sign up free at formspree.io and replace YOUR_FORM_ID in contact.html.
